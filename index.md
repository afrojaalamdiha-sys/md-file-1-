
# JavaScript - 7 Primitive Data Types

## 1. String
**Definition:** String is a data type used to store text or characters.

**Example:**
```js
let name = "Afroja";
let city = "Chittagong";
```

## 2. Number
**Definition:** Number is a data type used to store numeric values, including integers and decimals.

**Example:**
```js
let age = 22;
let price = 99.50;
```

## 3. Boolean
**Definition:** Boolean is a data type that represents true or false values.

**Example:**
```js
let isStudent = true;
let isMarried = false;
```

## 4. Undefined
**Definition:** Undefined means a variable has been declared but has not been assigned a value.

**Example:**
```js
let address;
console.log(address); // undefined
```

## 5. Null
**Definition:** Null represents an intentional absence of a value.

**Example:**
```js
let result = null;
console.log(result); // null

# JavaScript - Non-Primitive Data Types

## 6. Object

**Definition:** Object is a collection of key-value pairs.

**Example:**

    let user = {
        name: "Afroja",
        age: 22
    };



## 7. Array
**Definition:** Array is a data type used to store multiple values in a single variable.

**Example:**
```js
let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]);
```
